# Security policy

## Supported version

Security fixes currently target the latest revision of the default branch. No released version has a separate maintenance window yet.

## Reporting a vulnerability

Please do not disclose an exploitable vulnerability in a public issue. Use the repository's **Security → Report a vulnerability** form (GitHub private vulnerability reporting) when it is enabled.

If private reporting is unavailable, open a public issue that asks the maintainer to establish a private contact channel, but do not include vulnerability details, user data, credentials, recordings, or transcripts.

Useful private reports include the affected revision, Android version, reproduction steps, impact, and a minimal proof of concept. Remove personal data from logs before attaching them.
